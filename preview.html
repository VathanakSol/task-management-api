Running the live API

Run uvicorn app.main:app --reload from the project root, then select Live mode. If this file is opened through a different origin, the API must allow that origin through CORS. Live create, update, and delete requests modify the configured SQLite database.

Demo data is ephemeral. Live mode sends requests directly from your browser; no request is proxied or recorded by this console.
